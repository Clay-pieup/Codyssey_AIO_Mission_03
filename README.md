## 구현 요약
- MAC 연산: 반복문 2개로 n×n칸을 돌며 패턴과 필터의 같은 칸끼리 곱해 더한다. 외부 라이브러리 없이 점수(float)를 돌려준다.
- 동점 처리: 두 점수 차이의 절댓값이 1e-9보다 작으면 UNDECIDED(화면에서는 '판정 불가')로 본다.
- 성능 측정: `time.perf_counter()`로 MAC 호출만 10회 재서 1회 평균(ms)을 낸다. 입출력 시간은 뺀다.
- 라벨 정규화: 값의 앞뒤 공백을 지우고 소문자로 바꾼 뒤 표(`+`·`cross`→Cross, `x`→X)에서 찾는다. expected와 필터 키에 같은 함수를 쓴다.
- 스키마 검증: 키에서 크기 N을 꺼내 size_N 필터를 고르고, 패턴이 N×N 숫자 표인지 검사한다. 문제가 있으면 그 케이스만 FAIL로 처리하고 계속한다.
